# Transmute Games logo

The Games identity preserves the original circular transmutation emblem,
controller, downward arrow, and angular Transmute Games lettering. Its colors
follow Transmute Core: sage (`#526447`), pale sage (`#b7c9a0`), and paper
(`#f7f7f2`) on forest charcoal (`#101b18`).

- [Logo PNG](logo.png): the recolored original Games identity on forest charcoal.
- [Avatar PNG](avatar.png): 1024 × 1024 export for the GitHub organization avatar.
- [Core mark SVG](core-mark.svg): the unchanged engine mark for Core project links.
- [Social preview PNG](social-preview.png): 1200 × 630 sharing card.
- [Social preview SVG](social-preview.svg): self-contained composition with
  outlined text and embedded artwork.
- [Social background](social-background.png): artwork without text.
- [Minicraft logo](minicraft.webp): the project logo used in the profile table.

Keep the colors and proportions intact, including the dark background, and give
the logo clear space. The Games logo is raster artwork; the Core mark is vector.

The social card uses a dark forest background and an isometric pixel-art world
with tiled terraces, trees, and a stepped stone arch. The headline reads
**Make room for play.**, supported by **Tools for making 2D pixel games.**
Its compact signature reads **transmute / games**, connecting the card with Core's
signature. The serif accent is outlined Georgia Italic; recipients do not need
the font installed. The background export uses nearest-neighbor scaling to
preserve its pixel edges.

The technology row shows Java, Python, JavaScript, TypeScript, and C in pale
sage. Java is the reference engine; the other languages implement the shared
headless authoring subset. The row does not imply full engine feature parity.

## Sources

The Games logo was recolored and enlarged with OpenAI image generation on
2026-11-27 from the owner's supplied original Transmute Games logo.
The separate Core mark and shared palette come from [Transmute Core's logo](https://github.com/transmute-games/transmute-core/blob/62b336ba539ae263652dfea0744d26dbe55dfa96/assets/logo.svg).
The DM Sans lettering uses Core's bundled `website/public/fonts/dm-sans.woff2`;
its [SIL Open Font License](DM-Sans-LICENSE.txt) is retained here.
The Core sources were inspected at revision `62b336ba539ae263652dfea0744d26dbe55dfa96`.
The Minicraft logo is copied unchanged from Core's
[`website/public/minicraft-logo.webp`](https://github.com/transmute-games/transmute-core/blob/62b336ba539ae263652dfea0744d26dbe55dfa96/website/public/minicraft-logo.webp).
The pixel-world artwork was reworked with OpenAI image generation on
2026-11-27 from the earlier sculptural-world composition, at the owner's request
for a more pixelated treatment. It is illustrative artwork, not an engine screenshot.

Technology icons come from [Devicon](https://github.com/devicons/devicon/tree/32fe1d3b3f36ad11f90ab94f7db59738139c2bf6/icons)
at revision `32fe1d3b3f36ad11f90ab94f7db59738139c2bf6`. The source SVGs are retained
unchanged in `technology/`; the social card recolors their fills to pale sage.
See the retained [Devicon license](technology/LICENSE). Technology names and logos
belong to their respective owners.

Updating the GitHub organization avatar requires uploading `avatar.png` in the
organization's profile settings. Committing these files does not change it.
Upload `social-preview.png` to the social preview setting of each selected
repository; adding it here does not configure sharing previews automatically.
